# CHATBOT DE GESTIÓN DE VACACIONES

## Trabajo Práctico Integrador - Organización Empresarial

### Alumna

Martina Castro

### Objetivo

El objetivo de este proyecto es automatizar el proceso de solicitud de vacaciones dentro de una organización mediante un chatbot desarrollado en Python

### Funciones

* Validación de legajos de empleados
* Consulta de días de vacaciones disponibles
* Solicitud de días de vacaciones
* Aprobación o rechazo automático según las reglas de negocio
* Manejo de errores de entrada y validaciones

### Tecnologías Utilizadas

* Python
* GitHub
* Diagramas BPMN 2.0

### Estructura de Datos

El sistema utiliza una base de datos simulada mediante un diccionario que almacena información de los empleados y sus días disponibles
